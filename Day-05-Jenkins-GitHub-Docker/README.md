# Day 5 - Jenkins Integration with GitHub and Docker

## Topics Learned

### 1. Jenkins

Jenkins is an automation server used for Continuous Integration and Continuous Delivery.

### 2. Jenkins with GitHub

Learned how Jenkins connects with a GitHub repository and retrieves the source code.

### 3. Jenkins with Docker

Learned how Jenkins can execute Docker commands as part of a build process.

### 4. Jenkins Pipeline

Learned the basic flow:

GitHub → Jenkins → Build → Docker → Run

## What I Learned

- Jenkins can integrate with GitHub.
- Jenkins can automatically retrieve code from GitHub.
- Jenkins can execute Docker commands.
- Jenkins can be used to automate the build process.
