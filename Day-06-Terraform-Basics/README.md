# Day 6 - Terraform Basics

## Topics Learned

### 1. What is Terraform?

Terraform is an Infrastructure as Code (IaC) tool used to create and manage infrastructure using configuration files.

### 2. Infrastructure as Code

Infrastructure as Code allows infrastructure to be defined and managed using code instead of manually configuring resources.

### 3. Terraform Configuration Files

Terraform configuration files use the `.tf` extension.

### 4. Terraform Workflow

The basic Terraform workflow is:

```text
terraform init
        ↓
terraform plan
        ↓
terraform apply
