## What is DevOps?

DevOps is a combination of Development and Operations. It helps teams collaborate, automate tasks, and deliver software faster and more reliably.

## CI/CD Process

* **CI (Continuous Integration):** Developers frequently integrate code changes and use automated builds and tests to identify errors.
* **CD (Continuous Delivery):** Code is automatically built and tested and kept ready for deployment.
* **Continuous Deployment:** Changes that pass automated checks are automatically deployed to production.

## DevOps Stages

1. Plan
2. Code
3. Build
4. Test
5. Release
6. Deploy
7. Operate
8. Monitor

## Version Control Systems

### Centralized Version Control (CVCS)

A centralized system stores code and its history on a central server. Developers access the central server to share changes.

Example: SVN.

### Distributed Version Control (DVCS)

A distributed system gives each developer a local copy of the repository and its history. Developers can commit changes locally and share them later.

Example: Git.

## Basic Linux Commands

| Command  | Purpose                |
| -------- | ---------------------- |
| `pwd`    | Show current directory |
| `ls`     | List files             |
| `cd`     | Change directory       |
| `mkdir`  | Create a directory     |
| `touch`  | Create a file          |
| `cat`    | Display file content   |
| `cp`     | Copy files             |
| `mv`     | Move or rename files   |
| `rm`     | Remove files           |
| `clear`  | Clear terminal         |
| `whoami` | Show current user      |
